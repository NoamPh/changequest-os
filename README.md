# ChangeQuest OS

Organizational change is hard. This helps you think it through.

## What is this?

ChangeQuest OS is a browser-based tool for planning organizational changes. It walks you through the critical questions before you launch a change — scope, stakeholders, risks, and readiness gates.

## Getting started

```bash
npm install
npm run dev
```

## Stack

- React + TypeScript + Vite
- localStorage for persistence (no backend required)
