# פעלי-ספינר עבריים ל-Claude Code 🌀

מחליף את הפעלים שמופיעים ליד הספינר של Claude Code כשהוא "חושב"
(במקור באנגלית — *Thinking…, Simmering…, Noodling…*) בפעלים עבריים מצחיקים:
**מדרבק… · מכווצץ… · מסנטז… · מפבלש…**

## איך זה עובד

Claude Code (מגרסה 2.1.23 ואילך) תומך רשמית בהגדרה בשם `spinnerVerbs`
בתוך `settings.json`. המבנה המדויק (מאומת מול קוד ה-CLI):

```json
{
  "spinnerVerbs": {
    "mode": "replace",
    "verbs": ["מדרבק", "מכווצץ", "מסנטז", "מפבלש"]
  }
}
```

- `mode: "replace"` — משתמש **רק** בפעלים שלך.
- `mode: "append"` — מוסיף את הפעלים שלך **מעל** ברירות המחדל של Claude.

> הערה: זו הגדרה של **Claude Code (ה-CLI בטרמינל)**, לא של ה-API. הספינר הוא
> חלק מהממשק של הכלי, ולכן ההתאמה נעשית בקובצי ההגדרות שלו.

## התקנה מהירה

```bash
cd hebrew-spinner-verbs

# גלובלי — חל על כל הפרויקטים (~/.claude/settings.json):
./install.sh

# רק על הפרויקט הנוכחי (.claude/settings.json):
./install.sh --project

# להוסיף מעל ברירות המחדל במקום להחליף:
./install.sh --append
```

לאחר ההתקנה פתחו סשן חדש של Claude Code — הפעלים יופיעו ליד הספינר.
(אפשר גם להריץ `/status` כדי לראות אילו קובצי הגדרות נטענים.)

## התקנה ידנית

מזגו את התוכן של [`settings.json`](./settings.json) לתוך אחד מהקבצים:

| היקף | נתיב |
| --- | --- |
| משתמש (גלובלי) | `~/.claude/settings.json` |
| פרויקט (משותף) | `.claude/settings.json` |
| מקומי (אישי לפרויקט) | `.claude/settings.local.json` |

אם כבר יש לכם `settings.json`, הוסיפו רק את המפתח `"spinnerVerbs"` — אל תדרסו
את שאר הקובץ.

## עריכת רשימת הפעלים

הפעלים נמצאים ב-[`verbs.json`](./verbs.json) (מערך פשוט). ערכו/הוסיפו כרצונכם
והריצו שוב את `./install.sh`. הפעלים בהווה בזכר יחיד (מ־...) עובדים הכי טוב.

## הערה על כיווניות (RTL)

הטרמינל מציג את שורת הספינר בהקשר של שמאל-לימין, ולכן טקסט עברי עלול להיראות
מעט משונה לצד מונה הטוקנים. הפעלים עצמם נקראים תקין — זה עניין של תצוגת הטרמינל,
לא של ההגדרה.

## למה זה קובץ הגדרות ולא "פלאגין"?

`spinnerVerbs` נקרא מהיררכיית ה-`settings.json` של Claude Code (managed →
מקומי → פרויקט → משתמש). מנגנון הפלאגינים (skills / agents / hooks / MCP)
אינו חושף שדה ייעודי לדריסת פעלי-הספינר, ולכן הדרך הנתמכת והמובטחת היא דרך
`settings.json`. החבילה הזו עוטפת בדיוק את זה — קובץ מוכן + סקריפט שממזג אותו.
